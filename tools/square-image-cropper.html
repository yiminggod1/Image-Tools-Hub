Square Image Cropper

Crop an image to a 1:1 square.

How to use this tool

Choose the source image, set the crop frame or position you need, preview the composition, and download the new copy. Your original file remains unchanged.

Practical note

Move the crop position when the subject is not centered; the tool is built around a 1:1 frame.
