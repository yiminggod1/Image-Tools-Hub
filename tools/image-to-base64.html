Image to Base64

Convert a local image to a Base64 data string.

How to use this tool

Provide the required image or numeric input, review the information or settings, then copy or download the result. The original file stays unchanged.

Practical note

Base64 is an encoding rather than compression, so the resulting text is generally larger than the binary file.
