Image DPI Checker

Check image dimensions and print-related facts.

How to use this tool

Choose the source image, adjust the focused setting, inspect the preview or file facts, and download the new copy. The source file is not overwritten.

Practical note

Embedded DPI information is separate from pixel dimensions; changing pixels and changing a resolution label are different operations.
