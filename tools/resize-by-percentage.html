Resize Image by Percentage

Scale an image up or down by percentage.

How to use this tool

Choose the source image, set the destination requirement, run the operation, check the preview, and download the new copy. The original file stays unchanged.

Practical note

A percentage is relative to the current pixel dimensions, so 50% produces half the width and half the height.
