How to Reduce JPG File Size

Ways to reduce JPG size while controlling visible quality.

The practical approach

JPG size depends heavily on pixel dimensions, image detail, and export quality. For a photo, resizing before compression can make a much larger difference than repeatedly lowering quality. Avoid converting a JPG to PNG just to make it smaller; PNG is usually better suited to graphics, screenshots, and transparency.

What to do

For web photos, start with a sensible display width, then use JPG or WebP and inspect the result at 100% zoom.
