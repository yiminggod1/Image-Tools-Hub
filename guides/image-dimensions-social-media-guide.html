How to Check Image Dimensions Before Posting

Why pixel dimensions and aspect ratio matter when an image is going to a social or publishing platform.

Dimensions are pixels

An image's width and height describe its pixel dimensions. Those values are separate from file size in KB or MB.

Aspect ratio prevents surprises

An image can be large enough in pixels and still crop awkwardly if its shape does not match the destination. Check the ratio before you resize or crop.

Measure first, edit second

Start with the original dimensions, then choose whether you need a resize, crop, or both. This avoids repeatedly exporting an image just to discover that the shape is wrong.
